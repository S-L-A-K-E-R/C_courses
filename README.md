# C Programming & Algorithmics

A collection of **C programming and algorithmics teaching resources** intended primarily as a **reference and backup knowledge base for students**.

The repository now gathers active course material, bilingual exercises, homework assignments, projects, exams, and older teaching archives. Some sections are still being reorganized as the course evolves.
